JAK DODAC ZDJECIA ROSLIN
=========================

Kazdy produkt moze miec DWA zdjecia:
  - GLOWNE (np. miskant-memory.jpg)        - reprezentacyjne, ladne
  - DRUGIE (np. miskant-memory-2.jpg)      - wyglad "w sprzedazy", w doniczce

JAK TO DZIALA NA STRONIE:
- Pokazuje sie GLOWNE zdjecie
- Po najechaniu kursorem (lub dotknieciu na telefonie) wyswietla sie DRUGIE
- W rogu pojawia sie znacznik "1 / 2"
- Jesli plik "-2.jpg" nie istnieje, znacznik jest niewidoczny

NAZWY PLIKOW - TRAWY OZDOBNE:
  miskant-memory.jpg          + miskant-memory-2.jpg          -> Miskant 'Memory'
  miskant-malepartus.jpg      + miskant-malepartus-2.jpg      -> Miskant 'Malepartus'
  rozplenica.jpg              + rozplenica-2.jpg              -> Rozplenica 'Hameln'
  miskant-zebrinus.jpg        + miskant-zebrinus-2.jpg        -> Miskant 'Zebrinus'
  miskant-silver-charm.jpg    + miskant-silver-charm-2.jpg    -> Miskant 'Silver Charm'
  pennisetum-black-beauty.jpg + pennisetum-black-beauty-2.jpg -> Rozplenica 'Black Beauty'

NAZWY PLIKOW - DRZEWKA OZDOBNE:
  klon-palmowy.jpg     + klon-palmowy-2.jpg     -> Klon palmowy 'Bloodgood'
  sosna-gorska.jpg     + sosna-gorska-2.jpg     -> Sosna gorska 'Mops'
  jalowiec.jpg         + jalowiec-2.jpg         -> Jalowiec 'Skyrocket'
  wisnia-japonska.jpg  + wisnia-japonska-2.jpg  -> Wisnia japonska 'Kanzan'
  swierk-serbski.jpg   + swierk-serbski-2.jpg   -> Swierk serbski 'Nana'
  milorzab.jpg         + milorzab-2.jpg         -> Milorzab 'Mariken'
  katalpa.jpg          + katalpa-2.jpg          -> Katalpa kulista 'Nana'

  hero.jpg                                      -> Glowne zdjecie na gorze strony

REKOMENDACJE:
- Rozmiar: 800-1200 px szerokosci
- Format: JPG (preferowany)
- Jesli Windows zapisze plik jako .jfif - zmien rozszerzenie na .jpg
  (Eksplorator -> Widok -> Rozszerzenia nazw plikow -> prawym -> Zmien nazwe)
- Waga: 100-300 KB na plik
- Optymalizacja online: https://squoosh.app

PROPORCJE:
- Glowne zdjecia produktow:  3:4  (pionowe, np. 900 x 1200 px)
- Hero (gorne zdjecie):       4:5  (pionowe, np. 800 x 1000 px)
